## 🚀 Uruchomienie lokalne


git clone https://github.com/RomanDidkovskyi77433/dev-kolibri-app
cd dev-kolibri-app
./mvnw spring-boot:run

Otwórz w przeglądarce: http://localhost:8080/hello
